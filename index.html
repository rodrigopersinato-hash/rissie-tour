Como a Rissiê funciona

A árvore da empresa: do Grupo Rissiê saem os setores, de cada setor saem os processos e de cada processo, os passos.

Toque num setor para abrir os ramos. Toque num ramo para ver os passos. Arraste para mover e use dois dedos (ou a rodinha do mouse) para aproximar.
